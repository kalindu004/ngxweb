Privacy Policy

Last updated: 7 November 2026

This page describes the public website at https://ngxconsultants.com/. It matches the pages and scripts published here. It does not describe other systems, and it is not the terms of a consulting or managed-services engagement.

Who to contact

The site is published by NGX Consultants. The pages list offices in Colombo, Sri Lanka and Toronto, Canada, and the email address info@ngxconsultants.com. No street address is published on the site.

Questions about this page: admin@ngxconsultants.com.

What happens when you open a page

The pages are static HTML, CSS, and JavaScript. There is no account, web form, comment box, or file upload.

The site is hosted on GitHub Pages. Your browser requests the page files from GitHub Pages. Checked on 7 November 2026, the homepage response named GitHub as the server and did not set a cookie.

Each page also requests the Poppins font from Google Fonts (fonts.googleapis.com and fonts.gstatic.com). Google receives that request, including the IP address needed to send the font files. Google describes its handling in Google’s privacy policy. No other third-party script is included on these pages.

The scripts on the page open and close the menu, rotate the homepage slides, and show a WhatsApp link. They do not set cookies, do not use browser storage, and do not send browsing data to NGX or to an analytics service.

Analytics

Analytics is not running. No measurement ID is configured for this site. The pages do not load an analytics service and do not send page views. A real measurement ID can be added later only from an analytics property NGX controls. This page would need to be updated at the same time. It does not claim that any analytics product is active.

Links that leave this site

Nothing is sent to these services until you choose the link:

  • Talk to us and Book a Session open Microsoft Bookings at bookings.cloud.microsoft.
  • WhatsApp links open WhatsApp.
  • Email and phone links open the mail or phone app on your device.
  • The FAQ links to support.ngxconsultants.com. That is a separate site. Its pages are not part of this static website, and this policy does not describe them.

Those services apply their own policies. This website does not receive a copy of what you type there.

Messages you send

If you email, call, or message NGX, you choose what to include. This website does not store that message. No retention period is stated here, because the site does not define one.
